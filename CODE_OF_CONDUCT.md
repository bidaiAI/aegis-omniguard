# Code of Conduct

## Our pledge

We want Aegis OmniGuard to be a respectful, practical, and security-minded open-source project. Contributors and users should be able to discuss privacy, security, browser behavior, and AI risks without harassment or personal attacks.

## Expected behavior

- Be respectful and constructive.
- Assume good faith, but verify claims with evidence.
- Keep issue discussions focused on reproducible behavior.
- Redact secrets, private keys, tokens, personal data, and screenshots that expose sensitive information.
- Respect responsible disclosure for security vulnerabilities.

## Unacceptable behavior

- Harassment, threats, or personal attacks.
- Posting real secrets, private keys, tokens, or doxxing material.
- Encouraging misuse of the tool for credential theft, surveillance, or evasion.
- Publicly disclosing exploitable vulnerabilities before maintainers have had a reasonable chance to respond.

## Enforcement

Maintainers may remove comments, close issues, restrict participation, or report abuse when behavior puts users or the project at risk.

For security issues, use the process in [`SECURITY.md`](SECURITY.md).
