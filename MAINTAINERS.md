# Maintainers

## Primary maintainer

- GitHub: [`bidaiAI`](https://github.com/bidaiAI)
- Role: primary maintainer / core maintainer

## Maintainer responsibilities

- Review security-sensitive pull requests.
- Keep the Chrome Web Store listing and privacy claims aligned with source code behavior.
- Maintain the local-first scanning posture.
- Require regression tests for new detection rules.
- Keep public documentation accurate for users, reviewers, and downstream integrators.

## Release principles

- No telemetry by default.
- No cloud dependency for core DLP scanning.
- No raw secret logging.
- Store listing claims must be backed by source code or tests.
- Security-sensitive releases should include build/test evidence.
